💻 Implementation Details

Custom Data Structure Implementation

All data structures in this project are custom implementations using Python, not built-in lists or collections. This demonstrates true understanding of how these structures work internally.

Node Class

Contains data and a reference to the next node

class Node: def __init__(self, data): self.data = data self.next = None

LinkedList Class

Manages nodes and implements insert, delete, traverse

class LinkedList: def __init__(self): self.head = None def insert(self, data) def delete(self, key) def traverse()

Stack Class

Uses LinkedList internally for LIFO operations

class Stack: def __init__(self): self.items = LinkedList() def push(self, data) def pop() def peek()

Queue Class

Uses LinkedList internally for FIFO operations

class Queue: def __init__(self): self.items = LinkedList() def enqueue(self, data) def dequeue() def peek()
